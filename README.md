# Fortnite Screen Observer (prototype)

Prototype Android app for manually inspecting screenshots of Fortnite. It does not interact with Fortnite, automate matches, send taps, or farm rewards.

## Build
Open this project in Android Studio or use a compatible Android CI service. The project uses a standard Gradle Android application structure.

## Use
Choose a screenshot from your device. The prototype displays the image and a simple text field for notes. It does not perform OCR yet.
